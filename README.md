# Yevhen Leonidov

I'm a software architect and engineer from Ukraine and have been writing code since 2008. I design and build high-traffic backends, microservices, AI integrations, and web security systems.

## What I do

**[GLOBUS.studio](https://globus.studio)** - my software studio. We take on projects most studios pass on: complex backends, tricky integrations, performance-critical systems. Lean teams, realistic estimates, code you can build on.

**[BotBlocker](https://botblocker.top)** - my WordPress security platform. One plugin replaces a whole security stack: firewall, bot detection, rate limiting, CAPTCHA, 2FA, and anti-spam. Traffic is filtered before WordPress loads, so most attacks never reach the site at all.
